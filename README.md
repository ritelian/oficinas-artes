# Do Movimento à Tela — Oficinas de Artes 12.º ano

Página imersiva para orientar o Projeto 01 de Oficinas de Artes, com imagens hero em grande formato, secções full-screen, parallax suave, microanimações e layout responsivo.

## Publicar no GitHub Pages
1. Cria um repositório novo no GitHub.
2. Faz upload do ficheiro `index.html` para a raiz do repositório.
3. Em **Settings → Pages**, escolhe **Deploy from a branch**.
4. Seleciona a branch `main` e a pasta `/ (root)`.
5. Guarda. O GitHub apresenta o endereço público após a publicação.

## Notas
- A página usa imagens remotas do Wikimedia Commons e Google Fonts, por isso precisa de ligação à internet.
- O efeito parallax é feito em JavaScript e é automaticamente desativado para utilizadores com `prefers-reduced-motion` ativo.
- Em ecrãs pequenos, o layout adapta-se para uma coluna e preserva a legibilidade.
